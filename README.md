# SVGCN: 딥러닝 기반 학교폭력 예측 모델

> School Violence Graph Convolution Network (SVGCN)  
> 공공데이터와 GCN(Graph Convolutional Network)을 활용해 학교별 학교폭력 발생 빈도수를 예측하고, 예측값을 저위험/중위험/고위험 3단계로 분류하는 프로젝트입니다.

## 1. 프로젝트 개요

기존 학교폭력 대응은 사건 발생 이후의 사후 대응에 집중되는 경우가 많습니다. 이 프로젝트는 학교별 교육 환경, 과거 학교폭력 발생 패턴, 지역 범죄 데이터, 학교 간 유사도 정보를 활용하여 학교폭력 위험도를 사전에 예측하는 것을 목표로 합니다.

모델은 각 학교를 하나의 노드(node)로 보고, 학교 특성 패턴이 유사한 학교끼리 엣지(edge)로 연결합니다. 이후 GCN을 통해 개별 학교 정보뿐 아니라 유사한 환경의 이웃 학교 정보까지 함께 학습합니다.

## 2. 사용 데이터

분석 대상은 서울시 강북권 14개구 기준 고등학교 160개입니다.

| 데이터 | 설명 | 출처 |
|---|---|---|
| 학교별 위치정보 | 위도, 경도 | 학교알리미 |
| 학교별 교육 여건 | 학생수, 교원 1인당 학생수, 예방교육 시간, 학업중단률 | 학교알리미 |
| 학교폭력 데이터 | 학교폭력 심의 건수, 자체 해결 건수 | 학교알리미 |
| 지역 범죄 데이터 | 서울시 경찰서별 청소년 5대 범죄 현황 | 서울 열린데이터광장 |

> 원본 데이터 파일은 라이선스/용량/민감도 이슈를 피하기 위해 기본적으로 GitHub 업로드 대상에서 제외하는 것을 권장합니다. `data/README.md`에 데이터 설명과 출처를 정리했습니다.

## 3. 문제 정의

학교 `i`의 피처 벡터 `x_i`와 그래프 이웃 구조 `N(i)`를 입력으로 받아 2025년 학교폭력 발생 빈도수 `ŷ_i`를 예측합니다.

```text
ŷᵢ = f(xᵢ, N(i))
```

예측된 빈도수는 다음 기준으로 위험도로 변환합니다.

| 라벨 | 기준 |
|---|---|
| 저위험 | 0~1건 |
| 중위험 | 2~4건 |
| 고위험 | 5건 이상 |

## 4. 모델링 과정

### 4.1 데이터 전처리

- 학교별 자체 해결 건수와 심의 건수를 연도/학기별로 합산
- 문자형 컬럼 제거
- 17개 수치형 피처 구성
- `StandardScaler`로 피처 표준화
- 타겟인 학교폭력 빈도수는 `log1p` 변환 후 학습
- 예측 후 `expm1`로 원래 건수 단위 복원

### 4.2 KNN 그래프 구성

- 각 학교를 17개 피처 벡터로 표현
- 코사인 유사도 기반 KNN 사용
- 각 학교마다 가장 유사한 15개 학교 연결
- 양방향 엣지 생성
- 최종 그래프: 160개 노드, 3062개 엣지

### 4.3 GCN 모델 구조

```text
GCNConv(17 -> 8)
ReLU
Dropout(p=0.2)
GCNConv(8 -> 8)
ReLU
Dropout(p=0.2)
GCNConv(8 -> 1)
```

학습 설정:

| 항목 | 설정 |
|---|---|
| Optimizer | Adam |
| Learning rate | 0.0005 |
| Weight decay | 5e-4 |
| Loss | L1Loss |
| Epoch | 1000 |
| Hidden dimension | 8 |
| Split | Train 70% / Validation 15% / Test 15% |

## 5. 실험 결과

### 5.1 회귀 성능

| 모델 | MAE |
|---|---:|
| Baseline 평균 예측 | 2.8816 |
| SVGCN | 1.9983 |

SVGCN은 단순 평균 예측보다 낮은 MAE를 보였으며, 학교 간 유사도 기반 그래프 구조를 활용했을 때 예측 오차가 감소했습니다.

### 5.2 테스트 성능

| 지표 | 값 |
|---|---:|
| Test MAE | 1.9983 |
| Test RMSE | 2.5895 |
| Test R² | 0.3559 |
| Risk Accuracy | 0.7500 |

### 5.3 위험도 분류 결과

```text
Confusion Matrix
[[ 3  1  1]
 [ 0  5  1]
 [ 0  3 10]]
```

위험도 3단계 분류에서 테스트셋 기준 정확도 75%를 기록했습니다.

## 8. 한계점 및 개선 방향

- 데이터가 160개 학교로 제한되어 있어 딥러닝 모델 학습에는 표본 수가 적습니다.
- 2023~2025년 일부 기간 데이터만 사용했기 때문에 장기 시계열 패턴 반영에는 한계가 있습니다.
- 학교폭력 데이터는 신고/심의/자체 해결 기준에 따라 실제 발생 양상과 차이가 있을 수 있습니다.
- 향후 더 많은 연도, 지역, 학교급 데이터를 추가하면 일반화 성능을 개선할 수 있습니다.
- GCNExplainer, permutation importance 등을 활용해 주요 피처와 이웃 관계의 영향력을 해석할 수 있습니다.

## 9. 핵심 기여

- 학교를 독립적인 데이터포인트가 아니라 그래프 노드로 정의했습니다.
- 학교 특성 유사도를 기반으로 KNN 그래프를 구성했습니다.
- GCN을 활용해 주변 학교의 정보를 함께 반영하는 위험도 예측 구조를 설계했습니다.
- 예측값을 위험도 라벨로 변환하여 교육 현장에서 이해하기 쉬운 형태로 제시했습니다.
