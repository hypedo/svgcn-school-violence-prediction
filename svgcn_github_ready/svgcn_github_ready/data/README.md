# Data

이 폴더에는 모델 학습에 사용하는 학교 단위 데이터가 들어갑니다.

권장 파일명:

```text
school_data.xlsx
```

## 주요 컬럼

| 컬럼 | 설명 |
|---|---|
| SCHUL_NM | 학교명 |
| 구 | 자치구 |
| LTTUD | 위도 |
| LGTUD | 경도 |
| 교원/비율 | 교원 1인당 학생수 관련 지표 |
| 교육시간_23(1) ~ 교육시간_24(2) | 학교폭력 예방교육 시간 |
| 학업중단률_23, 학업중단률_24 | 연도별 학업중단률 |
| 범죄_23, 범죄_24 | 지역 청소년 범죄 관련 지표 |
| 총학생수 | 학교별 총학생수 |
| 구_학생수 | 자치구 단위 학생수 |
| 학폭_23(1) ~ 학폭_25(2) | 학교폭력 심의 건수 |
| 자체_23(1) ~ 자체_25(2) | 학교폭력 자체 해결 건수 |

## GitHub 업로드 주의

학교명과 학교폭력 관련 수치가 포함되어 있으므로, 공개 저장소에는 원본 데이터를 올리지 않는 것을 권장합니다. 공개가 필요하다면 출처, 라이선스, 비식별 처리 여부를 먼저 확인하세요.
